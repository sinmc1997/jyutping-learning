# 粵拼學習

按 `LEARNING_SITE_BLUEPRINT.md`（形態訓練營藍圖）做嘅粵拼學習網站：聽音、睇圖分聲調、分辨聲母韻尾、最小對立對比。
題目隨機生成，答錯記入錯題本，間隔重複（SM-2）自動安排複習。純前端，唔使伺服器。

## 內容（18 課）
- **聲調 6 課**：第 1–6 聲。三種題：睇音高圖揀聲調、由聲調揀調值、睇真字（例如「鳥」niu?）揀第幾聲。
- **聲母 6 組**：唇音、舌尖、舌根／喉、齒音、半元音、零聲母。
- **韻尾 4 組**：開尾、-i／-u、-m／-n／-ng、-p／-t／-k（入聲）。
- **揀正確粵拼**：干擾項只改一個部分（聲調、懶音聲母 n/l、ng/冇、韻尾 -n/-ng、-t/-k、aa/a）。
- **最小對立**：兩個音節只差一樣嘢，揀邊樣唔同（聲母／韻母／聲調）。

## 讀音
裝置有粵語語音（Windows「中文（香港）」、iPhone／Android 粵語）先會出 🔊 按鈕；冇就自動收埋。

## 檔案
- `index.html`：頁面殼＋樣式
- `engine.js`：通用引擎（與國際象棋網站相同）
- `content.js`：粵拼內容（課程、字表、生成器）
- `tests/validate.cjs`：每個生成器跑 1500 個 seed，檢查每題剛好 1 個正解
- `tests/smoke.cjs`：冒煙測試，用假 DOM 走一遍主流程

## 注意
- 字表約 110 個常用字，聲母組同韻尾組由拼寫自動推算（唔使人手標）。多音字（好、少、中、間、行…）唔會用嚟出「揀拼音」同「揀聲調」題。
- 字表嘅粵拼係按常見標準寫嘅，**首次使用前請對照你常用嘅粵拼字典核對**，發現錯咗改 `content.js` 嘅 `CHARS`。
- 最小對立嘅音節有啲係組合出嚟練習嘅（例如 si1 vs ma4），唔一定係真字，目的係練分辨。
