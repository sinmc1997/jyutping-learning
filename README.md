# 粵拼打字

學用**鍵盤同手機打粵拼**：先學粵拼拼寫規則，再自己打出粵拼，最後用你真正嘅輸入法打中文（計速度）。
純前端，唔使伺服器。網址：https://sinmc1997.github.io/jyutping-learning/

## 內容（11 課、13 關）
| 階段 | 課 | 做咩 |
|---|---|---|
| 拼寫規則 | 聲母 z c s j gw kw、aa／a、eo／oe、yu／jyu、韻尾、ng／零聲母 | 先揀啱拼法（識別），再自己打（生成） |
| 聲調 | 1–6 聲 | 睇音高圖揀數字、打聲調數字 |
| 打字 | 打單字（連聲調）、打詞語（聲調可省） | 打錯會話你錯喺聲母、韻母定聲調 |
| 實戰 | 輸入法打詞語、打句子 | 用你部機嘅粵拼輸入法打中文，計每分鐘字數 |

- **🎮 關卡**：13 關，答啱 80% 過關（★），90% ★★，全啱 ★★★，過咗先開下一關。
- **⏱ 計時挑戰**：60 秒內打得幾多個詞（打粵拼／輸入法打中文兩個模式），記最佳紀錄同每分鐘字數。
- **⌨️ 跟打文章**：隨機文章或者貼上自己嘅文章，逐個字顯示要撳嘅粵拼鍵，撳啱變色、打完自動跳下一個字；唔識讀嘅字可以自己補。
- **📱 輸入法教學**：電腦（Rime 小狼毫／鼠鬚管＋粵拼方案）、手機（TypeDuck、同文輸入法等）、打字技巧、舊式拼法對照。
- 學習引擎：間隔重複、智能揀題、答錯 2 題後再考、錯題本、統計（包括打字速度）、備份。

## 檔案
- `drill.js` 跟打文章介面（插件）；`index.html` 頁面殼；`engine.js` 通用引擎（同西洋棋網站共用）；`content.js` 粵拼內容、關卡、教學
- `tests/validate.cjs`：每課跑 1500 題；打字題「正解一定判啱、亂打一定判錯」；詞語唔打聲調都要判啱
- `tests/smoke.cjs`：假 DOM 走一遍主流程、打一關、開教學頁

## 注意
- 字音以單字本調為準（唔計變調）；有其他常用讀音嘅字（聽、坐、嚟、星、讀）唔出題。
- 詞庫：181 個詞語、48 句句子（變調字用口語讀音，例如 屋企 uk1 kei2）。
- 字表、詞語請對照粵語字典核對；發現錯就改 `content.js` 嘅 `RAW`／`WORDS`／`SENTS`。
- 輸入法 App 名同安裝步驟可能會變，以官方說明為準。
